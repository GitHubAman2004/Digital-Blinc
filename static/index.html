AIOps Operations Test Simulation Deck

Trigger hardware faults or network flaps to see how the dashboard components reflect anomalies. The scheduler runs collectors periodically to fetch data from mock API servers and updates the PostgreSQL database.

HPE OneView Physical Failures

Enclosure Fan Outage Simulates a complete fan assembly failure on Enclosure-01. Leads to severe blade heating.
Server Power Supply Failure Injects a redundant power supply failure on Blade Server 3 in Enclosure-01. Raises critical alert.
Storage Array Pool Degraded Degrades Storage Pool "SAN-Pool-01" by creating a raid failure. Shrinks free capacity.
Compute Thermal Warning Pushes server CPU temperatures above 85°C on Blade 2, Enclosure-02 due to thermal throttling.

Cisco APIC ACI Network Failures

Leaf Switch Power Down Simulates complete power loss to Leaf Switch 102. Drops switch health index to 0.
Interface Link Flapping Simulates packet drop thresholds and connection flapping on Spine-201 Interface ethernet 1/5.
ACI Fault F1024 (EPG Packet Drops) Creates a logical networking fault on Tenant Prod EPG App-DB due to packet drops.
